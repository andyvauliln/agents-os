# .gitignore

## What it is

The repo's `.gitignore`, a real file where every group of lines has a comment saying why. It keeps every `.env` keys file out of git, except `.env.example`, which holds key names only, and it lets the How it works, Details and Questions files of a keys file in. So the keys folder `.secrets/`, its `test/` and `live/` folders, `secrets.index.json` (key names only) and all their metadata files are in git and show in the tree; only the `.env` files with the values stay on the machine, and the page lists them as local-only without their text. It also leaves out dependencies and build output, Python caches, OS and editor files, Cursor's local state, research clones in `apps/temp/*/repo/`, each person's `.claude/settings.local.json`, the contents of `.claude/agent-memory-local/`, and what agents and workers write at run time in the `logs/` and `data/` folders under `agents/`. In those folders the folders themselves, their How it works, Details and Questions files and `.gitkeep` stay in git. For the project IDE it leaves out `.worktrees/`, where each run from the page works on its own branch, and `apps/project-IDE/data/page-store/notes/`, the owner's notes waiting on the server page, whose words the run that takes them files as an owner input.

## Who looks after it

It is written by the owner and knowledge-base-agent.

## When and how it changes

It changes when a kind of file must be kept out of git or let back in, such as keys files, build output or research clones.

## Who uses it, and when

It is read by git, the owner, every agent before it commits and project-ide-agent (ide-build checks the page tree against git).

## Where it is mentioned

It is described in `docs/rebuild-prompt.md`, `docs/README.md`, `apps/docs/rebuild-prompt.md` and its folder's How it works file `agent-os.index.md`.

## Related knowledge

It links to `.secrets/test/.env`, `.secrets/live/.env`, `apps/temp/`, `.worktrees/` (made by `apps/project-IDE/server/worktrees.py`) and `apps/project-IDE/data/page-store/notes/` (kept by `apps/project-IDE/server/notes.py`). The rules that apply to it come from `agents/system/CLAUDE.md` (section "Rules"), `docs/metadata.md` and `docs/README.md` (section "Keys and secrets").

## Keep in mind

- When you add an ignore line, add a comment saying why.
- `.playwright.env` is ignored: it holds where this machine keeps the browser for the page check, which differs on every machine.
