# .gitignore

## Summary

The repo's `.gitignore`, a real file where every group of lines has a comment saying why. It keeps every `.env` keys file out of git, except `.env.example`, which holds key names only, and it lets the How it works, Details and Questions files of a keys file in. So the keys folder `.secrets/`, its `test/` and `live/` folders, `secrets.index.json` (key names only) and all their metadata files are in git and show in the tree; only the `.env` files with the values stay on the machine, and the page lists them as local-only without their text. It also leaves out dependencies and build output, Python caches, OS and editor files, Cursor's local state, and research clones in `apps/temp/*/repo/`. The contents of runtime `logs/` and `data/` folders are not ignored today; whether they should be is open.

## Keep in mind

- When you add an ignore line, add a comment saying why.
