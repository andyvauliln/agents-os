# .gitignore

## Summary

The repo's `.gitignore`, a real file where every line has a comment saying why. It keeps secrets (`.secrets/`, `*.env`), local Claude Code and Cursor state, repositories cloned only for research, dependency and build output, and the content of runtime `logs/` and `data/` folders out of git, while the folders themselves stay through `.gitkeep`. Shared `.claude/` and `.cursor/` files are committed. Whether the symlinks inside ignored `data/` and `logs/` folders should still be committed is open.

## Keep in mind

- When you add an ignore line, add a comment saying why.
