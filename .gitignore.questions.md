`.gitignore` does not ignore `.secrets/` now. These items are in git and show in the tree:

1. The keys folder, `test/` and `live/`.
2. `secrets.index.json`, which has the key names only.
3. Their How it works, Details and Questions files.

Git ignores each `.env` file. The exception is `.env.example`, which has the names only. The page shows the `.env` files as local-only. It never reads or shows their text.
