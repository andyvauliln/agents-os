# .secrets/

## Summary

The single store for every private key, wallet key, API key and token. It sits at the repo root, outside `agents/`, so no agent session has it in its folder and no link can reach it; it is git-ignored and locked to the owner's user (folder 700, files 600). It holds `test/.env` with all test keys, `live/.env` with the same names and live values (later, owner only), and `secrets.index.json` with metadata but never values. Scripts get keys only through `load-secret`, at run time, and only the names their config lists.

## Keep in mind

- When anything needs a secret, go through `load-secret` and `secret_keys`; never put a value in a config, doc, log, prompt or link.
- When you touch `live/`, stop: only the owner does that.
