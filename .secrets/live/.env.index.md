# .env

## Summary

The live twin of the test `.env`: the same sections and key names, with live values. Only the owner edits it, and it is a later phase, so it does not exist yet. No agent reads or writes it; every level's Claude Code settings deny `.secrets/live/**`. Scripts get live keys only through `load-secret`, and only for owner-approved live runs. The owner decides per key which values differ from test.

## Keep in mind

- When you need a live key, ask the owner; an agent never reads, writes or switches itself to this file.
