# .env

## Summary

The one file that holds every test credential as `KEY=value` lines, grouped in comment sections (mode, models, platforms and accounts, notifications) with names prefixed per account or platform (in the prediction-market domain, for example, `POLYMARKET_ACCT1_API_KEY`). Scripts get their keys from it through `load-secret` at run time. Agents and the dev workflow may read and update it, since these are safe test keys. It is not split into more files unless that stops working.

## Keep in mind

- When you add a test key, put it in the matching section with its account or platform prefix and add the same name to `live/.env` and `secrets.index.json`.
- When a config or job needs a key, list its name in `secret_keys`; never copy the value anywhere else.
