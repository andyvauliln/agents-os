# .claude/

## Summary

The system level's Claude Code folder, laid out the same way at every level. A session started for the system loads what is here and nothing else: `CLAUDE.md`, the file every Claude reads first, with the project's rules and the system manager's instructions, its settings (which keep live keys out of reach), its skills and its helper agents; the docs for people are one level up, in the system's `docs/`. The helper agents today are the self-improvement agent, the knowledge base agent, which keeps the knowledge and writes the docs, and the project IDE agent, which builds the File Tree page and brings back what the owner leaves on it; each has its skills here. Rules, commands and workflows are still empty placeholders.

## Keep in mind

- When you need to share something from here with another level, hand it over as a data file; never link a `.claude/` folder or file.
- When you commit, leave out `settings.local.json` and `agent-memory-local/`.
