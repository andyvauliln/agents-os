# [style-name].md

## What it is

The pattern for a system-level output style: one Markdown file per style, with `name` and `description` in its frontmatter and a body that says how to answer (format proposed). No concrete style is named yet.

## Who looks after it

It is written by the owner or an agent through change-plan, when a real output style is made.

## When and how it changes

It changes when the output style format changes, or a real output style replaces the pattern. It is a name pattern, not a real item: it tells what each item made from it will hold. It is a proposal of an agent, not yet approved by the owner.

## Who uses it, and when
