# [skill-name]/

## What it is

The name pattern for the folder of one more system skill, named after the skill. It holds `SKILL.md`, the skill's entry point with its steps, and any supporting files next to it.

## Who looks after it

It is written by the owner or an agent through change-plan, when a new skill is made.

## When and how it changes

It changes when the skill layout changes, or a new skill is copied from it. It is a name pattern, not a real item: it tells what each item made from it will hold.

## Who uses it, and when

It is read by Claude Code started in agents/system/.

## Where it is mentioned

It is described in `agents/system/.claude/skills/` and its folder's How it works file `agents/system/.claude/skills/skills.index.md`.
