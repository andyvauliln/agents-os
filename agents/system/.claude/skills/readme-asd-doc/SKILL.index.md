# readme-asd-doc/SKILL.md

## What it is

The skill that writes README.asd.md, the ASD-STE100 twin of a README.md, at every docs level. It keeps the same headings in the same order and follows the ASD-STE100 rules: short sentences, active voice, present tense, one word with one meaning, numbered steps. It is used right after any README changes, so the owner can compare the two versions on the page's ASD-STE100 tab.

## Who looks after it

It is written by the owner and knowledge-base-agent.

## When and how it changes

It changes when the ASD-STE100 rules used, or the levels that have a README, change.

## Who uses it, and when

It is read by knowledge-base-agent.

## Where it is mentioned

It is described in its folder's How it works file `agents/system/.claude/skills/readme-asd-doc/readme-asd-doc.index.md`.
