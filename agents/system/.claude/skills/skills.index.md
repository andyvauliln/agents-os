## Summary

The system level's skills: each one a folder with a `SKILL.md` that tells an agent how to do one job well. The main one is `change-plan`, which every AI follows for every change: plan it, show it to the owner, build it, then move its knowledge home. The knowledge base agent's skills save and sort every input, write the How it works of every file and folder, and write each main doc: the vision, the README and the rebuild prompt for AI; more doc skills are added one by one. The project IDE agent's skills build and publish the File Tree page, with the build scripts inside `ide-build/`, and bring back what the owner leaves on it. Still open: which skills every agent shares.
