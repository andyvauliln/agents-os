# [domain-name]/

## Summary

One folder link per domain, named after the domain's folder and pointing at that domain's `data/`. Through it the system and the UI reach the domain's data and, one `subagents.link/` further down, the data of the levels below it. It is read-only, built by relink from the folder tree, listed in no links file, and removed when the domain goes.
