# conventions.md

## Summary

The rules that keep many agents consistent and machine-readable: agent names (unique ids, domain codes, versions, no renames), the `.link` rule and file links, script kinds, per-agent configs, the standard agent and `.claude/` folders, tests and research, child links, the links file, metadata file names, one job per file, where a new file goes, docs and git. Each section's tag names the files it governs. Trading rules are in the prediction-market domain's `trading-conventions.md`.

## Keep in mind

- When the owner decides or changes a rule, write the rule here and the decision in `decisions.md`.
- When you reorganise this doc, keep the section names [2.7.1] to [2.7.5] so older references still resolve.
