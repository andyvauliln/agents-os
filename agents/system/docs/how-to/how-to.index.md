# how-to/

## What it is

The system's runbooks, one guide per task: create an agent, add a worker, add or change a link, add an account or a key, add a platform or a model, add or run tests, record research, process an owner input, promote an agent to live, and stop or delete an agent. They are earlier guides, written before the docs at five levels, so some paths, names and numbers in them are old.

## Who looks after it

The knowledge base agent. The owner can edit a guide on the File Tree page.

## When and how it changes

A guide is rewritten when the system part it tells about is built or changed. Until then the guides stay as they are.

## Who uses it, and when

An agent or the owner who does one of these tasks, after the system docs in `agents/system/docs/`.

## Where it is mentioned

The system README, `agents/system/docs/README.md`.

## Related knowledge

The system README tells how each part named in the guides is built now; the rules for every session are in `agents/system/CLAUDE.md`.

## Keep in mind

- When you follow a guide, check each path and name in it against the system README first.
