# workers.md

## Summary

The index of every job in the system, gathered from every agent's jobs file: owner agent, job id, on or off, type, what runs, schedule, runner, output path and who reads it. It shows whether data is already collected before anyone adds a worker. Create and stop scripts and support agents keep it current; the UI lists from it. Today it holds the example jobs of the system, the prediction-market domain, strategy 1 and the example variant.

## Keep in mind

- When you need data, look here before adding a worker; if a job already makes it, link its output instead.
