# services/

## What it is

The logs of the acting services shared by several domains, one folder per service, one line per test or live action. No shared acting service exists yet, so it holds only the name pattern `[service]/`.

## Who looks after it

It is written by the shared acting services (none yet).

## When and how it changes

It changes when a shared acting service is added or removed. It is empty for now.

## Who uses it, and when

It is read by the system agent; sys-self-improvement-agent; and the owner, on the File Tree page.

## Where it is mentioned

It is described in `agents/system/docs/README.md` (section "Actions: test and live"), `agents/system/docs/README.md` (section "Logs"), `agents/system/logs/` and its folder's How it works file `agents/system/logs/logs.index.md`.
