# [domain-name]/

## Summary

One folder link per domain, named after the domain's folder and pointing at that domain's `research/` [19.13]. Through it the system reads the domain's research history and, one `subagents.link/` further down, that of the levels below it. It is read-only, built by relink from the folder tree, listed in no links file, and removed when the domain goes.
