# doc-outlines.md

## Summary

The trading layer of the system's three doc skills (vision, README and rebuild prompt): what the domain's own docs add to the general domain outline, such as the business logic and worked examples, and the outlines and lengths of the strategy and trading-agent docs below the domain. Each level's docs tell only their own story and sum up what they share with the level above in a sentence or two.

## Keep in mind

- When you write a strategy's or trading agent's doc, sum up what it shares with the level above in a sentence or two and describe only what differs.
- When you write a README here, leave out the inside of an agent; what it trades and when goes in its own docs.
