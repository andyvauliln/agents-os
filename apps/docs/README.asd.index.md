The apps README again in ASD-STE100 Simplified Technical English: the same content and section order, in short, simple, active sentences, so the owner can compare it with the README and check that the overview is clear.

## Who looks after it

The knowledge base agent, from `README.md`, following the ASD-STE100 rules: one topic per sentence, at most 25 words for a description and 20 for a step, present tense, one word for one meaning, numbered steps. The owner can also change it on the page.

Every time `README.md` changes, in the same change, right after it. The agent rewrites the changed sections and keeps the names exactly as in the README.

The owner, to compare it with the README; readers who prefer plain, controlled English; agents that need short, unambiguous rules about apps.
