# changelog.md

## Summary

The system-level history: what changed in the OS, when and why, newest first. Each entry gives the date, the change, the area (docs, system, domain, UI, routing) and a link to the decision or input behind it; per-agent changes stay in the agent's own folders and logs. The knowledge base agent adds an entry for every round and system-support agents for every system-level change; the owner and the UI read it. It sits with the project's records in `apps/project-IDE/data/`.
