# file-tree.md

## Summary

The annotated, numbered tree of the whole OS with one fully expanded example agent. It holds the tree with [n] numbers and one section per object (purpose, contents, writers and readers, open questions): the file docs of the knowledge base. It sits with the project's records in `apps/project-IDE/data/`, because the File Tree page is built from it; there every Markdown file opens as a readable page on white or black paper, with its raw lines one click away. The knowledge base agent updates it after owner answers; the owner reviews it object by object, and `create-agent` follows its example layout. Still open: an automatic drift check against the real folders.

## Keep in mind

- When you move or retire an object, keep a stub under its old number; numbers are never reused.
- When you add, move, rename or remove a file or folder, update `feature-map.md` in the same change.
