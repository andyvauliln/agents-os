# Plan: voice input for the page's AI boxes

Status: done · Request: in-20261009-1019 · Updated: 2026-10-09

## The request

You asked for a voice button on the page's AI inputs: press it to record, up to 5 minutes; the words then appear in the box, and sending gives them to the agent as usual. Transcription uses Groq's free speech models, switching to the next one when one hits a rate limit or fails. The Groq key goes into the secrets.

## The change

1. A microphone button next to the request box and the delete note box. Press to record, press again to stop; recording stops by itself at 5 minutes, with a timer. The text is added to what is already in the box, so you can read and fix it before sending.
2. The project IDE server gets `voice.py` [53.3.5] and the route `api/voice`: it sends the recording to Groq and returns the text. It tries the models listed in `server.config.json` in order (`whisper-large-v3-turbo`, then `whisper-large-v3`), skips a model for a while after a rate limit, and moves on after an error.
3. The key: `GROQ_API_KEY` in the git-ignored keys file `.secrets/test/.env`, named in the config's `secrets.keys`, never sent to the page or to Claude Code.
4. On claude.ai the page cannot use the microphone (claude.ai pages are not given it) and cannot reach Groq, so the button shows only on your own server.
