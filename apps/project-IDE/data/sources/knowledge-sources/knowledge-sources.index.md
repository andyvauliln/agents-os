# knowledge-sources/

## What it is

Earlier agent notes, kept but not referenced now: for each part of the system vision (`vision.md`), README (`readme.md`) and rebuild prompt (`rebuild-prompt.md`), what it rested on (inputs, decisions, tree notes) and its status when it was written.

## Who looks after it

Nobody writes it now; the notes are kept as they are.

## When and how it changes

It does not change. Whether its notes are used again is the owner's later decision.

## Who uses it, and when

Nobody reads it now. The doc skills take what a doc rests on from the records and the metadata files.

## Where it is mentioned

It is described in its folder's How it works file `apps/project-IDE/data/sources/sources.index.md`, which also names the pattern `[doc].md` for one such note.

## Related knowledge

The rules that apply to it come from `agents/system/CLAUDE.md` (section "Rules") and `docs/metadata.md`. What a doc rests on now is in the Details file of that doc (`sources`).
