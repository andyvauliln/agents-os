## Defaults

Built as "default, the owner may change it" because the notes leave the detail out: machinery script names `[name].system.js` and `load-secret.system.sh` / `.py`; start.sh calling run-agent through `git rev-parse`; every AI job and every job of the example variant, markets-catalog and get-polymarket-data switched off; `prompt: "run once"`; relink `--if-edited`, appended changed paths, `--changed` with no files as a full run, exit 1 on any error, child links only for existing folders, `@[name]` matching a domain folder or a registry row; check-links ignoring placeholder folders in subagents.link/; scheduler `--list` / `--run`; run-agent `--dry-run`; system log naming `[src]-YYYY-MM-DD.jsonl`; services log `YYYY-MM-DD.jsonl`; notifier to the system log; `AGENT_OS_TEST_RUN=1`; live branch and live gate answering `rejected`; clean-data rules; fetch steps stopping with "market source not set: ask the owner"; outputStyle and statusLine left out; the knowledge-sync inputs path; SI `<n>` = 3; level IDs in the `agent` fields; schema_version in the agent config; the news-digest route removed; tree notes renumbered by the rebuilder; requirements.txt with a comment only; helper memory files made on first run.

Since 2026-10-09 the defaults that belonged to trading (the example variant's jobs, markets-catalog and get-polymarket-data, clean-data rules, the market-source stop message, the services log naming, the live gate's account check, the news-digest route) left with the trading parts; new defaults: child links named after the domain folder and skipping a folder of domains, the merged `mode` falling back to `test`, `create-agent agents zz-domain-agent` as the throwaway check, the notifier check.
