# polymarket-prices.worker.link.log

## Summary

A read-only file link to `latest.log` of the domain's price collector job `polymarket-prices`, in the domain's `logs/jobs/polymarket-prices/`. The agent reads it to see when its price data is stale. Like every producer's `latest.*` file it is replaced each run, so the link never breaks (proposed). The `.worker` hint in the name keeps it apart from the prices data link. It is an optional link that relink builds from the links file.
