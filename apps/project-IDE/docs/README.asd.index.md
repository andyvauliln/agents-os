# README.asd.md

## What it is

The project IDE's README rewritten in ASD-STE100 Simplified Technical English: the same content and section order as `README.md`, in short sentences, active voice, simple approved words and numbered steps. The owner wants it to compare the plain README with a strict, controlled-language version. `README.md` is the source.

## Who looks after it

The knowledge base agent writes it from `README.md` with the `readme-asd-doc` skill. The owner can also change it on the page.

## When and how it changes

Every time `README.md` changes, right after it: the agent rewrites the changed sections in ASD-STE100, keeping the same headings, order, names and paths, and checks the sentence limits.

## Who uses it, and when

The owner, to compare it with `README.md` and to read the IDE's procedures as plain steps. Any reader or AI that wants short, one-meaning instructions.

## Where it is mentioned

Its first line names `README.md` as the source. The IDE's README lists it in the layout, `docs/file-tree.md` lists it, and the page is planned to show it as an ASD-STE100 tab on the README.

## Related knowledge

It must say exactly what `README.md` says. The ASD-STE100 rules it follows are the ones of the `readme-asd-doc` skill: one topic per sentence, at most 25 words for a description and 20 for a step, present tense, one word for one meaning.

## Keep in mind

- When README.md changes, update this file the same round, in the same section order.
- When a term has a name in README.md, use that exact name here.
