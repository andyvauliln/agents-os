# docs/

## Summary

The project IDE's own docs, as every app in `apps/` has them: the vision says what the IDE is for, the README describes its parts and where each one's docs are, and the rebuild prompt says how to build it again exactly. The knowledge base agent writes them with the same skills as the system's docs, using their outline for an app. They are not written yet: they come with the docs at every level, so they are written once inside the new hierarchy, and until then the system's README and rebuild prompt describe the IDE. Proposed.

## Keep in mind

- When you write or change these docs, go in the order vision, README, rebuild prompt, then check the system's docs above them.
