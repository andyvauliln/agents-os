# vision.md: open questions for the owner

- Should a routine check the page on a schedule and bring in your changes without the Apply changes button? It saves a step, but changes would reach the files without your go.
- When you work on your server, how should the page published on claude.ai learn about it: rebuilt and republished after each server round, or only when you ask? Today each copy is rebuilt from the repository on its own.
- Which statuses beyond "changed" should the page show, and when? It decides what the tree tells you at a glance.
- Is the order of the stage one work right: first tabs that are real files and correct metadata, then a view for every kind of file? It decides what the IDE agent does next.
