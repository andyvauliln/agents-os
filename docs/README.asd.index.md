# README.asd.md

## What it is

The project README again, in ASD-STE100 Simplified Technical English: the same content and section order as `README.md`, in short, simple, active sentences, so the owner can compare the two versions. `README.md` is its source.

## Who looks after it

The knowledge base agent, with the `readme-asd-doc` skill. The owner can also change it on the File Tree page; a change that is not in `README.md` goes into `README.md` first.

## When and how it changes

Every time `README.md` changes, right after it and before the rebuild prompt. The agent rewrites the changed sections under the ASD-STE100 rules: one topic per sentence, at most 25 words for a description and 20 for an instruction, present tense, one word for one meaning, numbered steps for procedures.

## Who uses it, and when

The owner, to compare it with the README and to read the project in the simplest words. Any reader or AI that wants short, unambiguous sentences.

## Where it is mentioned

`README.md` names it, the File Tree page shows it as the ASD-STE100 tab of the README, and the `readme-asd-doc` skill.

## Related knowledge

`README.md` is the only source of its content; it adds nothing of its own.

## Keep in mind

- When it and `README.md` disagree, `README.md` is right: fix this file.
- When you write it, use the names in `README.md` exactly.
