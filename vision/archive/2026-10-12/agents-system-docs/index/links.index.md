# links.md

## Summary

A readable list of every file link in every links file: the agent, where the link appears, the real file it points at, why, whether it is required and who added it. It is a view of the links index that relink writes, and shows who reads which file. Today it holds the example links of the system and of the prediction-market domain and the levels below it.

## Keep in mind

- When you add or change a link, edit the agent's links file and let relink run; this list only mirrors the links index.
