# Agent OS: Sub-agents index (v0.2)

Every sub-agent the tree names [2.18.3]: Claude Code sub-agents in a level's `.claude/agents/` (D-008), with their own context, tools and memory. Self-improvement is a sub-agent at every level (D-018), and system-support roles are sub-agents of the system (D-026). It is written by hand for now. Sub-agent file shape: see data-schemas.md, `schema-claude-md-files`. Names are unique across agents and sub-agents (D-012): check agents.md too.
