# services/[service]/

## Summary

The order logs of the domain's acting services, one folder per service (for example a Polymarket executor), in test and live: every order placed or blocked, with its market, side, size and fill. Every PnL number is computed from these logs. The format is still a proposal.

## Keep in mind

- When you place or block an order, write one line here; PnL is only ever computed from these logs.
