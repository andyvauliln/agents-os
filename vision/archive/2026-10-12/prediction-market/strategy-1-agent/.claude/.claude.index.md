## Summary

The strategy level's own Claude Code folder, in the standard layout every level has. A session started in the strategy folder loads only this: the strategy manager prompt `CLAUDE.md` [21.1.5], `settings.json` with the `.secrets/live/**` deny rules and the relink hook, and the strategy's sub-agents, above all the self-improvement sub-agent [21.1.1.1] that runs the strategy loop, with its memory in `agent-memory/`.
