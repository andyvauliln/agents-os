# docs/

## Summary

The strategy agent's own docs, and the proposed home of the strategy definition: `strategy.md` says in plain words what the strategy is, and a winning change is folded back into it together with the strategy's config and prompt. It also holds the strategy's `vision.md`, `README.md` (its parts and variations, with each trading agent's docs path) and `rebuild-prompt.md`, written to the strategy outlines in the domain's `doc-outlines.md`, and, like every agent's `docs/`, `decisions.md`, `notes.md` with the owner's comments and the answers, and file links to the docs it needs, such as the domain's comparison rules `trading-metrics.md`. `subagents.link/` gives the strategy every variant's docs, above all each `changes.md`. Open: whether the definition lives here or as a skill in `.claude/skills/`.

## Keep in mind

- When you fold a winning change back, update `strategy.md` together with the strategy's config and prompt.
- When you change this level's docs, check its parent's vision, README and rebuild prompt, in that order, up to the system.
