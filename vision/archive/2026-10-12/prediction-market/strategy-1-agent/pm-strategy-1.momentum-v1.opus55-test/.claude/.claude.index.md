# .claude/

## Summary

The trading agent's own Claude Code folder: the standard `.claude/` layout every level has, with its prompt, settings and tools. `CLAUDE.md` [24.5] is the prompt (strategy, run loop, allowed actions), built on the system's common prompt and the domain's trading layer. `settings.json` [24.6] denies `.secrets/live/**` and, as proposed, reruns relink after a links-file edit; `settings.local.json` holds personal overrides. `skills/` [25], `rules/`, `commands/`, `workflows/` and `output-styles/` hold reusable instructions and `agents/` [26] its own sub-agents, all placeholders for now; `agent-memory/` keeps sub-agent memory. No `.claude/` is linked in or out: each run starts Claude Code here (proposed) and sees only these files, while higher-level sub-agents reach it as linked data files. Still open: what a Cursor-routed variant uses instead.

## Keep in mind
