# run-[date].md

## Summary

A readable report of the agent's runs, the twin of `runs.jsonl`: one section per run, each ending with a one-line memory note for the next run, in a file named by its date. The agent writes it at the end of every run; the owner, the page and the agent's next run read it. The format is still a proposal.
