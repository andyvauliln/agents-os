# architecture.md

## Summary

How the system is built, one section per mechanism: agent levels, the standard agent folder and `.claude/`, child and file links, configs and routing, workers, jobs and the scheduler, scripts, logs and data, secrets, tests and research, docs, UI and apps. Each section's tag names the files it applies to. The knowledge agent updates it when a mechanism changes; agents and the owner read it after `overview.md`.

## Keep in mind

- When you have a file format, a rule or a step-by-step flow, put it in `data-schemas.md`, `conventions.md` or `safety.md`, or `flows.md`, and only point to it from here.
