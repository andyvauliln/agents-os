# glossary.md

## Summary

The shared vocabulary: one meaning per term, so the owner, agents and the UI use the same words. Terms are listed alphabetically, from agent, sub-agent and worker to route, test and live mode, trigger, version and important file, each with a pointer to the note that holds the detail. Trading words such as strategy, variant, champion and challenger are in the prediction-market domain's own trading glossary. The knowledge agent adds a term when a new one appears in inputs or docs, and everyone reads it. The file is still a proposal.
