# index/

## Summary

One index per kind of thing, so the owner, agents and the UI can find anything in the system. Six lists cover agents, jobs, sub-agents, acting services, apps and models, and a seventh mirrors every file link; the agents list is the registry of every name ever used. Create and stop scripts and system-support agents update the lists on every add, change or retirement, and the UI lists from them. A domain keeps its own lists, such as the prediction-market domain's trading accounts. Still open: hand-written lists, or generated from a JSON registry the UI also reads.

## Keep in mind

- When you add, change or retire an agent, job, sub-agent, service, app or model, update its list here in the same change.
- When an item is retired, keep its row with the new status; rows are never deleted.
