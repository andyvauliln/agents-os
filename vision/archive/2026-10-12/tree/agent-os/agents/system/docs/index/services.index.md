# services.md

## Summary

The index of every acting service, with its test or live mode and the ids of its accounts, never any secret. Create and stop scripts and system-support agents keep it current, and the UI lists from it. Its table format is still a proposal.

## Keep in mind

- When you list an account here, write its id only, never a key or other secret.
