# metrics.md

## Summary

How any agent is measured and compared, and the general conditions for going live. Every number belongs to one agent, one mode and one period: AI cost and tokens, run time, errors and tests. A test agent becomes a live candidate when its error rate is below the limit, no required link is broken and every enabled test passes; then the owner decides. Money numbers are in the prediction-market domain's `trading-metrics.md`. Most of it is proposed.

## Keep in mind

- When you want to change a metric, threshold or rule, propose it as "pending owner" in `decisions.md`; only the owner sets them.
- When you compare agents, never mix test and live numbers; each number belongs to one agent, one mode and one period.
