# README.asd.md

## What it is

Trading's README again, in ASD-STE100 Simplified Technical English: the same content and the same headings as `README.md`, in short, simple, active sentences, so the owner can compare the two and check that the overview is clear.

## Who looks after it

The knowledge base agent writes it from `README.md`, with the planned `readme-asd-doc` skill. The owner can also change it on the File Tree page.

## When and how it changes

It changes every time `README.md` changes, right after it. The agent rewrites the changed sections by the ASD-STE100 rules: one topic per sentence, at most 25 words for a description and 20 for a step, active voice, present tense, approved words, numbered steps.

## Who uses it, and when

The owner, to compare it with `README.md`; readers who prefer short, plain sentences; agents that need an unambiguous version of the README.

## Where it is mentioned

Trading's README and its rebuild prompt; the project's stage-one plan, which asks for an ASD-STE100 README next to every README.

## Related knowledge

`README.md` is its source and wins when the two disagree. It uses the same names for the same things as `README.md`. The system's `README.asd.md` follows the same rules.

## Keep in mind

- When `README.md` changes, change this file in the same round, section for section.
- When you write here, keep the names used in `README.md` exactly; never use two words for one thing.
