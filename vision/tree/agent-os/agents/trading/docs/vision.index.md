# vision.md

## What it is

Trading's vision: the first doc to read about trading. It says why trading has its own place in the Agent OS, how trading domains are arranged, how trading should work, the rules every trading domain shares, how a new trading domain is made, where trading stands and what is still open.

## Who looks after it

The knowledge base agent writes it with the `vision-doc` skill. The owner can also change it on the File Tree page.

## When and how it changes

It changes when an owner input or a decision changes what every trading domain shares: the money rules, the levels of agents, how a new domain is made, the stage of the project or an open question. The agent rewrites the passages it touches so the doc still reads as one story, then brings the README, its ASD-STE100 version and the rebuild prompt in line, in that order.

## Who uses it, and when

The owner and anyone new to trading read it first. Every trading domain agent reads it as background, and the knowledge base agent reads it before it writes trading's other docs or a trading domain's vision.

## Where it is mentioned

Trading's README and its ASD-STE100 version name it in their first section; trading's rebuild prompt says how it is written; the system's README names trading's docs; every trading domain's vision builds on it.

## Related knowledge

It sits below the system's vision, which holds what every agent shares, and above each trading domain's vision. Trading's README describes the same things exactly, with paths. The rules behind it are in the prediction-market domain's kept trading notes (`agents/trading/prediction-market/docs/`) and the owner's inputs.

## Keep in mind

- When you write here, add only what holds for every trading domain; one domain's detail belongs in its own docs.
- When you state a rule about money, say whether the owner decided it or it is our proposal.
- When the prediction-market domain is written again in stage two, update "Where it stands and what comes next".
